# 💱 Currency Converter (CLI)

Простой консольный конвертер валют на Python с кэшированием курсов. 
Проект создан для практики работы с API, файлами и Git.

## ✨ Возможности
- Конвертация между 160+ валютами по актуальному курсу.
- Кэширование курсов на 1 час (чтобы не спамить API).
- Автоматическое обновление кэша при истечении срока.
- Красивый вывод с разделителями тысяч.

## 🚀 Быстрый старт

### Требования
- Python 3.8+
- Установленный Git (опционально)

### Установка
1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/kozhukhar2293/currency-converter.git
   cd currency-converter
   ```

2. Создай и активируй виртуальное окружение: 
    # Windows
    ```bash
    python -m venv venv
    venv\Scripts\activate
    ```
    # macOS/Linux
    ```bash
    python3 -m venv venv
    source venv/bin/activate   
    ```
3. Установи зависимости:
    ```bash
    pip install requests    
    ```
### Использование
1. Запусти скрипт:
    ```bash
    python converter.py
    ```
2. Следуй инструкциям в консоли, введи валюту "из", валюту "в" и сумму (пример):
    ```text
    ------------ Конвертер валют ------------
    Использую кэш, курсы валют свежие
    Доступные валюты: AED, AFN, ALL, AMD, ...
    Из какой валюты: USD
    В какую валюту: EUR
    Сумма: 100
    100.00 USD = 92.00 EUR
    ```
